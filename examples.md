# Example Banking Questions

These examples demonstrate the types of analytical questions supported by Bank Data AI.

## Branch Analytics

- Which branch has the highest number of customers?
- Compare customer counts across branches.
- Which branch has the largest loan exposure?

## Account Analytics

- What is the average account balance?
- How many accounts are currently active?
- Show account-level balance statistics.

## Loan Analytics

- Which region has the highest total loan amount?
- What is the average loan amount by loan type?
- Compare loan status across loan types.

## Credit Card Analytics

- Which customers have high credit utilization?
- Compare credit limits across customers.
- Which cards have the highest outstanding balance?

## Transaction Analytics

- What are the largest transactions?
- Show transaction volume by date.
- Compare transaction amounts across categories.

## Employee Analytics

- Which employees have the highest attrition?
- Compare average salary across departments.
- Summarize employee demographics.

## Demo Flow

Natural-language question
→ Dynamic schema discovery
→ LLM SQL generation
→ Read-only validation
→ MySQL execution
→ Result table
→ Explanation
→ Visualization
